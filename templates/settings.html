How it works:
When a Manager approves an RFQ, the system automatically finds all active vendors matching the RFQ region and sends them a bidding invitation email via Resend API.

Must be from your verified Resend domain (e.g. noreply@shadowfax.click).

This name appears in the "From" field of all emails sent to vendors.

The URL vendors will use to open the quote form (e.g. https://shadowfax.click).

🔑 Resend API Setup Guide

1
Sign up at Resend
Go to resend.com → Create a free account
2
Verify your domain
Resend Dashboard → Domains → Add your domain → Add DNS records in your domain provider
3
Add API key to Railway
Railway → Your Project → Variables → Add RESEND_API_KEY=re_xxxx
4
Set sender email above
Use any address from your verified domain, e.g. noreply@yourdomain.com — no inbox needed!
